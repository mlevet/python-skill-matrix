# Start Here

This repo is a personal Python interview-preparation system.
One goal: make you interview-ready, session by session.

---

## The 10-second start

1. Open [dashboard.md](dashboard.md)
2. Click Priority #1
3. Read the 30-second explanation aloud
4. Solve the linked drill
5. Update mastery in [matrix/skill_matrix.md](matrix/skill_matrix.md)
6. Click Next Topic on that page

Do this daily. Each session is 25–40 minutes.

If you want a pre-planned session, open [TODAY.md](TODAY.md) instead.

## Mastery scale

| Score | Meaning |
|---|---|
| 0 | Unknown |
| 3 | Recognized but weak |
| 5 | Understand basics |
| 7 | Can explain in an interview |
| 10 | Can explain, code, debug, and teach |

## Priority formula

`Priority = freq_weight × (10 − mastery) × freshness_weight`

Higher score = study sooner. Formula details: [scoring_model.md](matrix/scoring_model.md)

---

## Hall of Pain rule

Every time you blank, get surprised, or fail a drill: add an entry to
[hall_of_pain.md](hall_of_pain.md). Review it before every real
interview. ADHD brains learn fastest from externalized mistakes.
